## Architecture Adaptations (Metis-Identified Fixes)

These corrections resolve contradictions in ARCHITECTURE.md. Implementers MUST apply these:

### A1. User Table Unification
- **Problem:** ARCHITECTURE.md defines two incompatible user tables — better-auth's `"user"` (TEXT PK) and the app DDL `"user"` (SERIAL PK).
- **Resolution:** Use better-auth's `"user"` table as the SINGLE source of truth. Add `role` and `is_active` via `user.additionalFields`. Drop the app DDL user table entirely.
- **Impact:** `production_session.operator_id` becomes `TEXT REFERENCES "user"(id)` instead of `INT`.

### A2. Next.js 16 Breaking Changes
- **Problem:** ARCHITECTURE.md code samples use `middleware.ts` and synchronous `cookies()`/`headers()`.
- **Resolution:** Rename `middleware.ts` → `proxy.ts`. All `cookies()`, `headers()`, `params`, `searchParams` calls MUST be `await`ed. Read `node_modules/next/dist/docs/01-app/02-guides/upgrading/version-16.md` before writing any server component.
- **Skill:** Load `/next-best-practices` and `/next-compile` for every Next.js task.

### A3. RabbitMQ Naming Canonicalization
- **Problem:** Three naming schemes appear in §2, §5.1, and §12.
- **Resolution:** Canonicalize on §12: queues `spindle.entry`/`spindle.exit`/`health.*`, routing keys `entry.count`/`exit.count`/`camera.#`/`model.#`/`esp32.#`.

### A4. Camera Status Enum Mapping
- **Problem:** RabbitMQ health messages use `online|offline|error` but the DB table uses `active|inactive|error`.
- **Resolution:** Persistence worker translates: `online→active`, `offline→inactive`, `error→error`.

### A5. spindle_pass_id Ownership
- **Problem:** Both edge (message schema) and DB (DEFAULT gen_random_uuid()) claim to generate the UUID.
- **Resolution:** Edge generates UUID. DB column keeps UUID type but removes DEFAULT. Same ID links entry + exit events.

### A6. Monitoring Page (10th Screen)
- **Problem:** dashboard.pen has 9 screens; no monitoring page exists in the design file.
- **Resolution:** Build a 10th screen at `/monitoring` with embedded Grafana panels using `<iframe>` embeds. Custom Grafana dashboards provisioned via JSON in Phase 7.

### A7. Font Swap
- **Problem:** Current scaffold uses Geist font; design requires Inter.
- **Resolution:** Replace Geist with Inter in root layout during Phase 1.

### T-006: Supabase Migration — Application Tables

**File:** `supabase/migrations/002_app_tables.sql`

**Action:** Create camera, detection_model, production_session, spindle_pass, detection_event tables. Key adaptation from A1: `production_session.operator_id` is `TEXT REFERENCES "user"(id)`. Key adaptation from A5: `spindle_pass.spindle_pass_id` has NO DEFAULT — edge provides UUID.

```sql
CREATE TABLE camera (
    camera_id     SERIAL PRIMARY KEY,
    camera_code   VARCHAR(10) NOT NULL UNIQUE,   -- e.g., 'CAM-01' — matches RabbitMQ message camera_id
    name          VARCHAR(50) NOT NULL,
    location      VARCHAR(100),
    position_type VARCHAR(10) NOT NULL CHECK (position_type IN ('entry','exit')),
    status        VARCHAR(20) NOT NULL DEFAULT 'active'
                  CHECK (status IN ('active','inactive','error')),

    created_at    TIMESTAMPTZ NOT NULL DEFAULT now()

CREATE TABLE detection_model (
    model_id      SERIAL PRIMARY KEY,
    model_name    VARCHAR(100) NOT NULL,
    version       VARCHAR(20) NOT NULL,
    architecture  VARCHAR(20) NOT NULL CHECK (architecture IN ('YOLO11','RT-DETR')),
    accuracy      FLOAT,
    mlflow_run_id VARCHAR(100),
    is_active     BOOLEAN NOT NULL DEFAULT false,
    deployed_at   TIMESTAMPTZ
);

CREATE TABLE production_session (
    session_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    shift_label      VARCHAR(50),
    start_time       TIMESTAMPTZ NOT NULL DEFAULT now(),
    end_time         TIMESTAMPTZ,
    total_spindles   INT NOT NULL DEFAULT 0,
    total_matched    INT NOT NULL DEFAULT 0,

);

CREATE TABLE spindle_pass (

CREATE TABLE detection_event (

    raw_count          INT NOT NULL,
    confidence_avg     FLOAT,
    processing_time_ms INT
```

### T-009: better-auth Server Configuration

**File:** `lib/auth.ts`

**Action:** Create the better-auth server instance. Key points:
- Use `pg` Pool for database (direct Postgres connection, NOT Supabase REST).
- Use `nextCookies()` plugin (MUST be last plugin).
- 8-hour session expiry for shift-based work.
- `additionalFields` for `role` and `is_active`.
- `emailAndPassword.requireEmailVerification: false` (internal factory system).

```typescript
import { betterAuth } from 'better-auth'
import { nextCookies } from 'better-auth/next-js'
import { Pool } from 'pg'

export const auth = betterAuth({
  database: new Pool({ connectionString: process.env.DATABASE_URL }),
  plugins: [nextCookies()],  // MUST be last plugin
  session: {
    expiresIn: 60 * 60 * 8,   // 8-hour shift session
    updateAge: 60 * 60,        // refresh token every 1 hour
  },
  emailAndPassword: {
    enabled: true,
    requireEmailVerification: false,
  },
  user: {
    additionalFields: {
      role: { type: 'string', required: true, defaultValue: 'operator', input: false },
      is_active: { type: 'boolean', required: true, defaultValue: true, input: false },
    },
  },
})
```

**CRITICAL:** Test with the direct (non-pooled) Supabase connection string first. Supabase's pgBouncer pool (transaction mode) can break session-based operations. Use the connection string from Supabase Dashboard → Settings → Database → Connection string (direct, port 5432), NOT the pooled one (port 6543).

### T-017: proxy.ts — RBAC Guards + Unauthorized Page

**Files:** `proxy.ts`, `app/unauthorized/page.tsx`

**Action:**

1. **proxy.ts** (Next.js 16 replacement for middleware.ts — see adaptation A2):

```typescript
import { auth } from '@/lib/auth'
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'
import { headers } from 'next/headers'

const ROLE_ROUTES: Record<string, string[]> = {
  '/reports':          ['supervisor', 'admin'],
  '/settings':         ['admin'],
  '/monitoring':       ['admin'],
}

export async function proxy(request: NextRequest) {
  const session = await auth.api.getSession({ headers: await headers() })

  if (!session) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  if (!session.user.is_active) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  const path = request.nextUrl.pathname
  const requiredRoles = Object.entries(ROLE_ROUTES).find(([route]) =>
    path.startsWith(route)
  )?.[1]

  if (requiredRoles && !requiredRoles.includes(session.user.role)) {
    return NextResponse.redirect(new URL('/unauthorized', request.url))
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/((?!login|forgot-password|api/auth|_next|favicon.ico).*)'],
}
```

**CRITICAL:** This file is `proxy.ts` at the project root, NOT `middleware.ts`. Next.js 16 renamed this. The `headers()` call MUST be `await`ed (async in Next.js 16). Read `node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/proxy.md` to verify the exact API contract.

```python
Supabase persistence layer.
Uses supabase-py client with service_role key (bypasses RLS).
"""
from supabase import create_client
from supabase.lib.client_options import ClientOptions

class SupabasePersistence:
    def __init__(self, url: str, service_key: str):
        self.client = create_client(
            url, service_key,
            options=ClientOptions(auto_refresh_token=False, persist_session=False)
        )

    def insert_spindle_entry(self, data: dict):
        """INSERT into spindle_pass with entry fields. Status = 'in_progress'."""
        self.client.table('spindle_pass').insert({
            'spindle_pass_id': data['spindle_pass_id'],   # Edge-generated UUID
            'session_id': data['session_id'],
            'entry_count': data['deduplicated_count'],
            'entry_time': data['timestamp'],
            'status': 'in_progress',
        }).execute()
        # Increment total_spindles on production_session
        # Use RPC or manual SELECT + UPDATE
        self._increment_session_counter(data['session_id'], 'total_spindles')

    def update_spindle_exit(self, data: dict):
        """UPDATE spindle_pass with exit fields + reconciliation status."""
        spindle_id = data['spindle_pass_id']
        # Fetch entry record to compare counts
        entry = self.client.table('spindle_pass').select('entry_count').eq(
            'spindle_pass_id', spindle_id
        ).single().execute()

        entry_count = entry.data['entry_count']
        exit_count = data['deduplicated_count']
        matched = entry_count == exit_count
        delta = abs(entry_count - exit_count) if not matched else 0
        status = 'matched' if matched else 'mismatched'

        self.client.table('spindle_pass').update({
            'exit_count': exit_count,
            'exit_time': data['timestamp'],
            'status': status,
            'mismatch_delta': delta,
        }).eq('spindle_pass_id', spindle_id).execute()

        # Update session counters
        counter = 'total_matched' if matched else 'total_mismatched'
        self._increment_session_counter(data['session_id'], counter)

    def update_camera_status(self, data: dict):
        """UPDATE camera status. Applies enum mapping (A4): online→active, offline→inactive."""
        status_map = {'online': 'active', 'offline': 'inactive', 'error': 'error'}
        db_status = status_map.get(data['status'], 'error')
        camera_code = data['camera_id']  # e.g., "CAM-01" — matches camera.camera_code column
        self.client.table('camera').update({
            'status': db_status,
        }).eq('camera_code', camera_code).execute()

    def _increment_session_counter(self, session_id: str, field: str):
        """Increment a counter on production_session. Uses SELECT + UPDATE (no RPC)."""
        current = self.client.table('production_session').select(field).eq(
            'session_id', session_id
        ).single().execute()
        new_val = current.data[field] + 1
        self.client.table('production_session').update({
            field: new_val,
        }).eq('session_id', session_id).execute()
```

```python
"""
Frame capture module.
- Production: captures from USB cameras via OpenCV VideoCapture
- Development: reads from .mp4 test video files in /data/test_videos/
- Outputs: JPEG-compressed, base64-encoded frames
"""
import cv2
import base64
import time
import logging
from typing import Optional, Tuple

logger = logging.getLogger('frame-capture')

class FrameCapture:
    def __init__(self, camera_id: str, source: str, target_fps: int = 30):
        """
        Args:
            camera_id: Camera identifier (e.g., 'CAM-01')
            source: USB device path ('/dev/video0') or video file path ('/data/test.mp4')
            target_fps: Target capture FPS
        """
        self.camera_id = camera_id
        self.source = source
        self.target_fps = target_fps
        self.cap: Optional[cv2.VideoCapture] = None
        self.last_frame: Optional[bytes] = None  # JPEG bytes for MJPEG server
        self.actual_fps: float = 0.0

    def open(self):
        """Open the video source."""
        if self.source.startswith('/dev/'):
            self.cap = cv2.VideoCapture(self.source, cv2.CAP_V4L2)
            self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1920)
            self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 1080)
            self.cap.set(cv2.CAP_PROP_FPS, self.target_fps)
        else:
            self.cap = cv2.VideoCapture(self.source)
        if not self.cap.isOpened():
            raise RuntimeError(f"Cannot open camera source: {self.source}")
        logger.info(f"Camera {self.camera_id} opened: {self.source}")

    def capture_frame(self) -> Tuple[Optional[str], Optional[bytes]]:
        """
        Capture and return one frame.
        Returns: (base64_encoded_jpeg, raw_jpeg_bytes) or (None, None) on failure
        """
        if self.cap is None or not self.cap.isOpened():
            return None, None
        ret, frame = self.cap.read()
        if not ret:
            # If reading from video file, loop back to start
            if not self.source.startswith('/dev/'):
                self.cap.set(cv2.CAP_PROP_POS_FRAMES, 0)
            return None, None

        # Resize to model input size (640x640) for inference
        resized = cv2.resize(frame, (640, 640))
        _, jpeg_buf = cv2.imencode('.jpg', resized, [cv2.IMWRITE_JPEG_QUALITY, 85])
        jpeg_bytes = jpeg_buf.tobytes()
        b64_frame = base64.b64encode(jpeg_bytes).decode('utf-8')

        # Store full-res JPEG for MJPEG streaming
        _, full_jpeg = cv2.imencode('.jpg', frame, [cv2.IMWRITE_JPEG_QUALITY, 80])
        self.last_frame = full_jpeg.tobytes()

        return b64_frame, jpeg_bytes

    def release(self):
        if self.cap:
            self.cap.release()
```

```python
"""
Roboflow API inference client.
Posts base64-encoded frames to the Roboflow hosted inference endpoint.
Returns: list of detections with [bbox, class, confidence].
Filters: confidence < 0.85 → discarded (NFR-06).
"""
import requests
import time
import logging
from typing import List, Dict, Any

logger = logging.getLogger('inference')

CONFIDENCE_THRESHOLD = 0.85  # NFR-06: hard filter

class RoboflowInference:
    def __init__(self, api_key: str, workspace: str, project: str, version: str):
        self.api_key = api_key
        self.endpoint = f"https://detect.roboflow.com/{project}/{version}"
        self.session = requests.Session()

    def detect(self, base64_frame: str, camera_id: str) -> Dict[str, Any]:
        """
        Send frame to Roboflow API for detection.
        Returns: {
            'detections': [{'x','y','width','height','class','confidence'}],
            'raw_count': int,
            'filtered_count': int,
            'confidence_avg': float,
            'latency_ms': int
        }
        """
        start = time.monotonic()

        response = self.session.post(
            self.endpoint,
            params={'api_key': self.api_key},
            data=base64_frame,
            headers={'Content-Type': 'application/x-www-form-urlencoded'},
            timeout=5,
        )
        response.raise_for_status()
        result = response.json()

        latency_ms = int((time.monotonic() - start) * 1000)

        all_detections = result.get('predictions', [])
        raw_count = len(all_detections)

        # Filter by confidence threshold (NFR-06)
        filtered = [d for d in all_detections if d.get('confidence', 0) >= CONFIDENCE_THRESHOLD]
        filtered_count = len(filtered)

        confidence_avg = (
            sum(d['confidence'] for d in filtered) / filtered_count
            if filtered_count > 0 else 0.0
        )

        logger.info(
            f"Camera {camera_id}: {raw_count} raw → {filtered_count} filtered "
            f"(avg conf: {confidence_avg:.2f}, latency: {latency_ms}ms)"
        )

        return {
            'detections': filtered,
            'raw_count': raw_count,
            'filtered_count': filtered_count,
            'confidence_avg': round(confidence_avg, 4),
            'latency_ms': latency_ms,
        }
```

### T-032: Edge Program — Cross-Camera Deduplication

**File:** `services/edge/deduplication.py`

**Action:** Merge detections from two cameras at the same checkpoint using pre-computed homography matrices.

```python
"""
Cross-camera deduplication.
Projects bbox centers from each camera to a shared ground plane via
pre-computed homography matrices (ArUco calibration done offline).
Merges pairs with Euclidean distance ≤ 30mm (NFR-07).
"""
import numpy as np
from typing import List, Dict, Tuple

DEDUP_RADIUS_MM = 30.0  # NFR-07

class CrossCameraDeduplicator:
    def __init__(self, H1: np.ndarray, H2: np.ndarray):
        """
        Args:
            H1: 3x3 homography matrix for camera 1 (maps image coords → ground plane)
            H2: 3x3 homography matrix for camera 2
        """
        self.H1 = H1
        self.H2 = H2

    def project_to_ground(self, detections: List[Dict], H: np.ndarray) -> np.ndarray:
        """Project bbox centers to ground plane coordinates."""
        if not detections:
            return np.empty((0, 2))
        centers = np.array([[d['x'], d['y']] for d in detections], dtype=np.float64)
        # Homogeneous coordinates
        ones = np.ones((centers.shape[0], 1))
        homogeneous = np.hstack([centers, ones])
        projected = (H @ homogeneous.T).T
        # Normalize homogeneous coords
        projected = projected[:, :2] / projected[:, 2:3]
        return projected

    def deduplicate(
        self,
        cam1_detections: List[Dict],
        cam2_detections: List[Dict]
    ) -> int:
        """
        Merge detections from two cameras. Returns unique count.
        """
        ground1 = self.project_to_ground(cam1_detections, self.H1)
        ground2 = self.project_to_ground(cam2_detections, self.H2)

        if ground1.shape[0] == 0:
            return ground2.shape[0]
        if ground2.shape[0] == 0:
            return ground1.shape[0]

        # Greedy nearest-neighbor matching
        matched_cam2 = set()
        unique_count = 0

        for p1 in ground1:
            distances = np.linalg.norm(ground2 - p1, axis=1)
            nearest_idx = np.argmin(distances)
            if distances[nearest_idx] <= DEDUP_RADIUS_MM and nearest_idx not in matched_cam2:
                matched_cam2.add(nearest_idx)
                # This is a duplicate — count once
            unique_count += 1  # Count cam1 detection

        # Add unmatched cam2 detections
        unique_count += ground2.shape[0] - len(matched_cam2)

        return unique_count
```

**NOTE for implementer:** The homography matrices H1 and H2 must be pre-computed offline via ArUco marker calibration. For the capstone demo, hardcode identity matrices (no projection) or use a simple test matrix. The deduplication logic itself is what matters — the calibration is a separate offline step.

```python
FIFO Reconciler.
- On ENTRY event: push (spindle_pass_id, count, timestamp) to deque.
- On EXIT event: pop front of deque, compare counts.
- Result: MATCH (delta=0) or MISMATCH (delta≠0).

  orphan detection (entries older than 5 min → marked as timeout).
"""

import time
import logging
from collections import deque
from typing import Optional, Dict, Any
from datetime import datetime, timezone, timedelta

logger = logging.getLogger('reconciler')

MAX_BUFFER_SIZE = 50
ORPHAN_TIMEOUT_SECONDS = 300  # 5 minutes

class FIFOReconciler:
    def __init__(self):
        self.buffer: deque = deque(maxlen=MAX_BUFFER_SIZE)

    def push_entry(self, session_id: str, count: int) -> str:
        """Push an entry event. Returns the generated spindle_pass_id."""
        spindle_pass_id = str(uuid.uuid4())
        entry = {
            'spindle_pass_id': spindle_pass_id,
            'session_id': session_id,
            'entry_count': count,
            'entry_time': datetime.now(timezone.utc).isoformat(),
        }
        self.buffer.append(entry)
        logger.info(f"ENTRY: {spindle_pass_id} count={count} buffer_depth={len(self.buffer)}")
        return spindle_pass_id

    def pop_exit(self, exit_count: int) -> Optional[Dict[str, Any]]:
        """
        Pop the oldest entry and reconcile with exit count.
        Returns reconciliation result or None if buffer is empty.
        """
        self._purge_orphans()

        if not self.buffer:
            logger.warning("EXIT event with empty buffer — no entry to reconcile")
            return None

        entry = self.buffer.popleft()
        entry_count = entry['entry_count']
        matched = entry_count == exit_count
        delta = abs(entry_count - exit_count)
        status = 'matched' if matched else 'mismatched'

        result = {
            'spindle_pass_id': entry['spindle_pass_id'],
            'session_id': entry['session_id'],
            'entry_count': entry_count,
            'exit_count': exit_count,
            'status': status,
            'mismatch_delta': delta if not matched else 0,
        }

        logger.info(
            f"EXIT: {entry['spindle_pass_id']} entry={entry_count} exit={exit_count} "
            f"→ {status} (delta={delta}) buffer_depth={len(self.buffer)}"
        )
        return result

    def _purge_orphans(self):
        """Remove entries older than ORPHAN_TIMEOUT_SECONDS."""
        now = datetime.now(timezone.utc)
        cutoff = now - timedelta(seconds=ORPHAN_TIMEOUT_SECONDS)
        while self.buffer:
            oldest_time = datetime.fromisoformat(self.buffer[0]['entry_time'])
            if oldest_time < cutoff:
                orphan = self.buffer.popleft()
                logger.warning(f"ORPHAN: {orphan['spindle_pass_id']} timed out after {ORPHAN_TIMEOUT_SECONDS}s")
            else:
                break

    @property
    def depth(self) -> int:
        return len(self.buffer)
```

### T-034: Edge Program — RabbitMQ Publisher

**File:** `services/edge/publisher.py`

**Action:** AMQP publisher that sends detection events and health telemetry to the VPS RabbitMQ broker.

```python
"""
RabbitMQ publisher for edge node.
Publishes to:
  - detection.events / entry.count — on spindle entry
  - detection.events / exit.count  — on spindle exit
  - health / camera.status         — every 5s per camera
  - health / esp32.heartbeat       — every 5s
All messages: JSON, delivery_mode=2 (persistent), schema_version="1.0".
"""
import pika
import json
import logging
from datetime import datetime, timezone

logger = logging.getLogger('publisher')

class EdgePublisher:
    def __init__(self, rabbitmq_url: str):
        self.url = rabbitmq_url
        self.connection = None
        self.channel = None

    def connect(self):
        params = pika.URLParameters(self.url)
        self.connection = pika.BlockingConnection(params)
        self.channel = self.connection.channel()
        # Declare exchanges (idempotent — ensures they exist)
        self.channel.exchange_declare('detection.events', exchange_type='direct', durable=True)
        self.channel.exchange_declare('health', exchange_type='topic', durable=True)
        logger.info("Connected to RabbitMQ")

    def publish_entry(self, data: dict):
        """Publish spindle entry detection event."""
        message = {
            'schema_version': '1.0',
            'event_type': 'spindle_detection',
            'checkpoint': 'entry',
            **data,
            'timestamp': datetime.now(timezone.utc).isoformat(),
        }
        self._publish('detection.events', 'entry.count', message)

    def publish_exit(self, data: dict):
        """Publish spindle exit detection event."""
        message = {
            'schema_version': '1.0',
            'event_type': 'spindle_detection',
            'checkpoint': 'exit',
            **data,
            'timestamp': datetime.now(timezone.utc).isoformat(),
        }
        self._publish('detection.events', 'exit.count', message)

    def publish_camera_health(self, camera_id: str, status: str, fps: float):
        """Publish camera health telemetry."""
        message = {
            'schema_version': '1.0',
            'event_type': 'camera_health',
            'camera_id': camera_id,
            'status': status,
            'fps_actual': round(fps, 1),
            'timestamp': datetime.now(timezone.utc).isoformat(),
        }
        self._publish('health', 'camera.status', message)

    def _publish(self, exchange: str, routing_key: str, message: dict):
        body = json.dumps(message)
        self.channel.basic_publish(
            exchange=exchange,
            routing_key=routing_key,
            body=body,
            properties=pika.BasicProperties(
                delivery_mode=2,  # Persistent
                content_type='application/json',
            ),
        )
        logger.debug(f"Published to {exchange}/{routing_key}: {body[:100]}...")

    def close(self):
        if self.connection and self.connection.is_open:
            self.connection.close()
```

### T-035: Edge Program — MJPEG Stream Server

**File:** `services/edge/mjpeg_server.py`

**Action:** Lightweight HTTP server that streams MJPEG frames from each camera. The Next.js dashboard `<img>` tags point to these endpoints.

```python
"""
MJPEG HTTP stream server.
Endpoints:
  GET /stream/{camera_id}  → multipart/x-mixed-replace MJPEG stream
Each frame includes headers:
  Content-Type: image/jpeg
  X-Timestamp: ISO8601
  X-Camera-FPS: float
"""
import threading
import time
import logging
from http.server import HTTPServer, BaseHTTPRequestHandler
from typing import Dict, Optional

logger = logging.getLogger('mjpeg-server')

class MJPEGHandler(BaseHTTPRequestHandler):
    """HTTP request handler for MJPEG streams."""

    # Class-level reference to frame sources (set by MJPEGServer)
    frame_sources: Dict[str, 'FrameCapture'] = {}

    def do_GET(self):
        # Parse camera_id from path: /stream/CAM-01
        parts = self.path.strip('/').split('/')
        if len(parts) != 2 or parts[0] != 'stream':
            self.send_error(404)
            return

        camera_id = parts[1]
        if camera_id not in self.frame_sources:
            self.send_error(404, f"Camera {camera_id} not found")
            return

        self.send_response(200)
        self.send_header('Content-Type', 'multipart/x-mixed-replace; boundary=frame')
        self.send_header('Cache-Control', 'no-cache, no-store, must-revalidate')
        self.send_header('Access-Control-Allow-Origin', '*')
        self.end_headers()

        source = self.frame_sources[camera_id]
        try:
            while True:
                jpeg_bytes = source.last_frame
                if jpeg_bytes is None:
                    time.sleep(0.1)
                    continue

                self.wfile.write(b'--frame\r\n')
                self.wfile.write(b'Content-Type: image/jpeg\r\n')
                self.wfile.write(f'X-Timestamp: {time.strftime("%Y-%m-%dT%H:%M:%S.000Z")}\r\n'.encode())
                self.wfile.write(f'X-Camera-FPS: {source.actual_fps:.1f}\r\n'.encode())
                self.wfile.write(f'Content-Length: {len(jpeg_bytes)}\r\n'.encode())
                self.wfile.write(b'\r\n')
                self.wfile.write(jpeg_bytes)
                self.wfile.write(b'\r\n')

                time.sleep(1.0 / 15)  # ~15 FPS stream rate
        except (BrokenPipeError, ConnectionResetError):
            logger.info(f"Client disconnected from {camera_id} stream")

    def log_message(self, format, *args):
        pass  # Suppress default access logs

class MJPEGServer:
    def __init__(self, host: str = '0.0.0.0', port: int = 8080):
        self.host = host
        self.port = port
        self.server: Optional[HTTPServer] = None

    def start(self, frame_sources: Dict):
        """Start the MJPEG server in a background thread."""
        MJPEGHandler.frame_sources = frame_sources
        self.server = HTTPServer((self.host, self.port), MJPEGHandler)
        thread = threading.Thread(target=self.server.serve_forever, daemon=True)
        thread.start()
        logger.info(f"MJPEG server started on {self.host}:{self.port}")

    def stop(self):
        if self.server:
            self.server.shutdown()
```
